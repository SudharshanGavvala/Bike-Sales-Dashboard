# 🚲 Bike Sales Dashboard

An interactive **Bike Sales Dashboard** created using Microsoft Excel to analyze bike purchasing behavior and customer demographics.

## 📊 Dashboard Overview

The dashboard provides insights into:

- Regional Bike Sales Distribution
- Gender-wise Bike Sales
- Age Bracket Analysis
- Commute Distance and Bike Purchases
- Impact of Children on Bike Purchases
- Cars Owned vs Bike Purchases
- Home Ownership and Bike Purchases
- Occupation and Education Analysis

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers / Filters
- Data Analysis
- Data Visualization

## 📈 Key Analysis

### Regional Sales
The dashboard compares bike purchases across:
- Europe
- North America
- Pacific

### Customer Demographics
Analysis includes:
- Gender
- Age brackets
- Number of children
- Home ownership
- Cars owned

### Lifestyle Analysis
The dashboard examines how lifestyle factors such as:
- Home ownership
- Cars owned
- Children
- Commute distance

relate to bike purchasing behavior.

### Occupation & Education
Bike purchases are analyzed across different occupations and education levels.
